# Логотип

Исходные файлы, присланные владельцем продукта:

- `logo-wordmark.png` — знак и надпись, 664×144;
- `logo-mark.png` — только знак, 256×297.

Они лежат здесь не для красоты, а чтобы вектор в коде можно было ПЕРЕСОБРАТЬ
и сверить. Знак в шапке (`web/app/layout.tsx`) и значок вкладки
(`web/public/icon.svg`) нарисованы вектором, а не вставлены картинкой: так он
остаётся чётким на любом экране, берёт цвет из фирменной переменной и не
требует лишнего запроса за файлом.

## Геометрия, снятая с файла

Не на глаз. Координаты сняты по пикселям, а сторона треугольника и величина
среза подобраны перебором по наименьшему расхождению с оригиналом:

- поле 256×297;
- срез правого нижнего угла 43×43 под 45°;
- треугольники со стороной 39, прямой угол слева сверху;
- сетка: шаг 41 по горизонтали, 42,5 по вертикали;
- ряды (y → x первых углов): 43 → 44, 85; 86 → 44, 85; 128 → 44, 85;
  170 → 44, 85, 126, 167; 213 → 44, 85, 126.

Расхождение вектора с присланным файлом — 1,78% пикселей, и все они на
сглаженных диагоналях. Среднее отличие по каналу — 0,37%.

## Цвет

**#be2c28.** Снят из обоих файлов: это самый частый непрозрачный цвет в них.

До логотипа на сайте стоял #b02b26 — я подобрал его на глаз, когда логотипа
не было. Теперь `--brand` равен фирменному, а `--brand-deep` (нажатие,
нижняя граница кнопки) пересчитан в ту же сторону: #9a211e.

В тёмной теме `--brand` светлее — #cf3a33: красный с бумаги на тёмном фоне
теряет контраст.

## Чего здесь нет

**Шрифта надписи.** В шапке слово «Liberterra» набрано системным шрифтом
сайта и покрашено в фирменный красный, как в логотипе. Это близко, но не то
же самое: у присланной надписи своё начертание. Чтобы совпало точно, нужен
либо файл шрифта, либо надпись вектором — скажите, и сделаю.
